### Metric Definitions
1. **Avg Gemini Call (s):** Average time taken by Gemini to run Google Maps grounding and output the structured JSON response containing the places and PlaceIDs.
2. **Avg Places API Call (s):** Average time taken to verify all PlaceIDs in parallel against the Google Places API Details endpoint.
3. **Grounded Rate (%):** The percentage of successful Gemini requests that contained any grounding metadata chunks returned from Google Maps.
4. **Verification Rate (%):** The percentage of model-generated places where the PlaceID was valid (Places API returned `OK`) AND the fuzzy string match score between the generated place name and the retrieved place name was $\ge 85\%$.
